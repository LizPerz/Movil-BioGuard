# BioGuard Móvil

BioGuard es una aplicación móvil de salud y monitoreo biométrico diseñada para ofrecer seguridad, control y seguimiento de pacientes en tiempo real.

## Características Principales

*   **Monitoreo Biométrico:** Seguimiento en tiempo real de los signos vitales a través de la integración con dispositivos portátiles (wearables).
*   **Guardián Nocturno:** Un sistema de monitoreo continuo durante la noche que alerta sobre cualquier irregularidad detectada.
*   **Interfaz Moderna y Accesible:** Un diseño centrado en el usuario, con temas oscuros, acentos neón y alto contraste para una mejor visibilidad y experiencia.
*   **Gestión de Medicamentos:** Herramientas integradas para el control y recordatorio de la medicación del paciente.
*   **Seguridad:** Control de acceso seguro y protección de datos médicos sensibles mediante pines de acceso de 8 caracteres.

## Tecnologías Utilizadas

*   **Lenguaje:** Kotlin
*   **UI:** Jetpack Compose 
*   **Arquitectura:** MVVM (Model-View-ViewModel)
*   **Asincronismo:** Corrutinas y Flow
*   **Red:** Retrofit para consumo de APIs
*   **Base de Datos Local:** Room Database

## Instalación y Ejecución

1. Clona este repositorio:
   ```bash
   git clone https://github.com/LizPerz/Movil-BioGuard.git
   ```
2. Abre el proyecto en **Android Studio**.
3. Permite que el proyecto se sincronice con Gradle.
4. Ejecuta la aplicación en tu emulador (recomendado con soporte Skia/Hardware acelerado) o en un dispositivo físico.
